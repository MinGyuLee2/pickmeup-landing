# 지도 빌드 도구

랜딩페이지의 지도 그림(`assets/` 안의 SVG)을 만드는 스크립트입니다. 페이지 자체는 빌드 없이 동작하고, **지도를 다시 만들거나 지역·경로를 바꿀 때만** 쓰면 됩니다.

| 스크립트 | 만드는 파일 | 쓰이는 곳 |
|---|---|---|
| `build_map.py` | `map-dark.svg`, `map-light.svg` + 경로 좌표(표준 출력) | 여의도 상세 지도: 첫 화면 배경, 차량 화면 내비, 기다리는 사람 장면, 카드 |

필요한 것: Python 3(표준 라이브러리만 사용), `curl`.

## 1. 원본 데이터 받기

```bash
tools/fetch_data.sh
```

`tools/data/` 아래에 약 3MB를 받습니다(OpenStreetMap Overpass API). Overpass 서버가 바쁘면 자동으로 다시 시도합니다.

## 2. 여의도 상세 지도 + 경로

```bash
python3 -I tools/build_map.py tools/data/osm assets 37.5163 126.9021 37.5216 126.9243
```

인자: `원본폴더 출력폴더 출발위도 출발경도 도착위도 도착경도`

- 출력되는 `route`(지도 단위 1600×917 좌표)는 실제 도로망에서 계산한 최단 경로입니다. 일방통행은 무시합니다.
- 현재 페이지의 경로는 이 출력에서 출발부의 짧은 꺾임을 손으로 다듬어 `M88.7 798.0 … L707.7 560.3`로 쓰고 있습니다. 경로를 바꾸면 `index.html`의 `cdRoute`·`webRoute` 등 지도 단위 경로와 픽업 핀 좌표(`707.7, 560.3`)를 함께 바꿔 주세요.
- 범위는 스크립트 위쪽 `LON0, LON1, LAT0, LAT1`입니다.
